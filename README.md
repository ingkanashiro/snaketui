# snaketui
A lightweight, extremely bare bones, classic snake game. The simplest way to play snake.

## Installation
Just download the binary from the releases!
(Note: Currently, only Linux support is available)

After downloading, you can run it from a terminal by referring to its path. However, we suggest you to create a **symlink** on your bin. Just run the following command in your terminal.

```bash
sudo ln -s /path/to/snaketui/binary /usr/local/bin/snake
```

Once that's done, you just need to run `snake` on your terminal to play! The game keeps track of your score and will print it after losing.
